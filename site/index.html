LLM prompt
出门前，先清洗。

Ctxward 坐在你的应用和每一个 LLM 提供商之间，自动检测、脱敏、可逆加密 prompt 中的 PII、密钥和内部标识符。无需改代码，模型永远看不到原始数据。

Every prompt scanned, redacted and tokenized before it hits the wire. No SDK changes. The model never sees the raw data.

PIPELINE / 工作原理

五道工序，零代码改动

Ctxward 是透明代理。设置系统代理指向它，所有 LLM 请求自动经过脱敏管线。

检测
Detect
Regex / 熵检测 / Presidio，递归扫描 JSON、SSE、OOXML、PDF
脱敏
Redact
就地脱敏 PII，模型永远看不到原始值
可逆加密
Tokenize
AES-GCM-SIV 可逆 token，管理员可恢复，模型不可
人工审批
Review
敏感 prompt 排队等人工审批后再转发
转发
Forward
清洗后的请求发往 LLM，响应可选择再次过滤
TRUST MODEL / 信任模型

不可审计的隐私工具，就是后门

Ctxward 靠透明赢得信任，而非靠隐秘。

白名单 MITM

Whitelist-only decryption

TLS 解密仅限已知 LLM 提供商 SNI。其余连接全部透传，你完全控制名单。

密钥永不出机

Key never leaves

根 CA 私钥本地生成，0600 权限存储，永不导出、上传或记录日志。

完全可审计

Fully auditable

Apache-2.0 开源 Rust。每条检测规则、每个策略决策、每行 MITM 逻辑都可检视。

ARCHITECTURE / 架构

一核两壳，同源同策

成熟的 Rust 引擎是单一事实源。两副交付壳共享同一套策略、标签与审计格式。

CTXWARD CORE — RUST ENGINE
detect · redact · tokenize · review · policy · audit · OPA · session · attachments · SSE

桌面端主线 main

Desktop — transparent take-over

Clash 式透明接管。Tauri 壳、系统代理、本地根 CA。单用户。开源增长引擎。

网关次线 secondary

Gateway — reverse proxy

无头反向代理。多租户 per-Bearer。Kubernetes 就绪。企业变现线。

CAPABILITIES / 引擎能力

数据面，已生产就绪

引擎今天就能作为反向代理运行。docker compose up

语言无关

Language-agnostic

应用零改动，不需要 SDK 包装。指向代理即生效。

深度格式扫描

Deep format scanning

JSON、SSE、OOXML 节点级重写(docx/xlsx/pptx)、PDF 内容流重写、multipart 附件。

五路决策

Five-way decisions

allow / redact / tokenize / review / block。按标签、按主体、OPA strict-merge。

可逆 Tokenize

Reversible tokenization

进程内 AES-GCM-SIV。密钥来自环境变量，永不落盘。管理员可解密；模型不可。

会话关联

Session correlation

跨对话轮次标签聚合，阻断拆分载荷渗出(split-payload exfil)。

可观测

Observable

Prometheus 指标、/readyz 探针、JSONL 审计(仅 hash)、内嵌 /admin 控制台。

流式 SSE 脱敏

Streaming SSE

逐事件脱敏 + 流感知故障安全。永不产生中流 502。

供应链安全

Supply chain

cosign 签名镜像、CycloneDX SBOM、cargo-deny + cargo-audit + gitleaks CI。
