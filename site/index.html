How it works

Five stages, zero code changes

Ctxward is a transparent proxy. Point your system proxy at it, and every LLM request passes through the pipeline automatically.

🔍
Detect
Regex, entropy, Presidio — recursive scan across JSON, SSE, OOXML, PDF
🛡
Redact
Strip PII in-place. The model never sees the original value.
🔑
Tokenize
Reversible AES-GCM-SIV tokens. Admins can recover; the model cannot.
📋
Review
Sensitive prompts queue for human approval before forwarding.
✅
Forward
Clean request goes to the LLM. Response optionally re-filtered.
Trust model

A privacy tool you can't inspect is a backdoor

Ctxward earns trust through transparency, not secrecy.

🔒

Whitelist-only MITM

TLS decryption is restricted to known LLM provider SNIs. Every other connection passes through untouched. You control the list.

🗝

Key never leaves

The root CA private key is generated locally, stored with 0600 permissions, and never exported, uploaded, or logged. Period.

📖

Fully auditable

Apache-2.0 licensed Rust. Every detection rule, every policy decision, every line of MITM logic is open to inspection.

Architecture

One core, two shells

A mature Rust engine is the single source of truth. Two delivery shells sit on top — same policy, same labels, same audit format.

Engine capabilities

Production-ready data plane

The engine runs today as a reverse proxy. docker compose up and you're live.

🌍

Language-agnostic

Apps stay unchanged. No SDK wrapper, no code changes. Just point at the proxy.

📄

Deep format scanning

JSON, SSE events, OOXML node-level rewrite (docx/xlsx/pptx), PDF content-stream rewrite, multipart attachments.

⚖

Five-way decisions

allow / redact / tokenize / review / block — per label, per principal, OPA strict-merge.

🔄

Reversible tokenization

AES-GCM-SIV in-process. Key from env, never disk. Admins can detokenize; the model cannot.

🔗

Session correlation

Cross-turn label aggregation defeats split-payload exfiltration across chat turns.

📊

Observable

Prometheus metrics, /readyz probe, JSONL audit (hashes only, never raw PII), embedded /admin console.

⚡

Streaming SSE

Per-event redaction with stream-aware fail-safe. Never a mid-stream 502.

🛡

Supply chain

cosign-signed images, CycloneDX SBOM, cargo-deny + cargo-audit + gitleaks in CI.
